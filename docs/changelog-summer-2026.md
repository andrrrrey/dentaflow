# DentaFlow — обновления системы: июнь–август 2026

> Сводный документ по всем правкам и нововведениям за лето 2026 (июнь, июль, август). Сгруппировано по месяцам, внутри месяца — по модулям. Каждый пункт — реально выкаченное изменение (по истории разработки).

**Ключевые вехи периода:**
- 🤖 Запущена подсистема **ИИ-обзвона** (голосовой робот + Asterisk + кампании) — от первого тест-звонка до масштабирования на 20 одновременных линий.
- 📅 Полностью переработан модуль **«Расписание»** и углублена интеграция с **1Denta** (вебхуки, перерывы, длительности, авто-синхронизация).
- 💬 Достроен **центр коммуникаций**: чаты ботов, двусторонняя переписка, реалтайм-счётчики и пуши.
- 🎁 Появились **бонусная программа** и **мотивация персонала**.
- ☎️ Добавлен второй провайдер телефонии **Ростелеком (ВАТС)** и альтернативный синтез речи **fish.audio**.
- 🆕 Подключён канал **ВКонтакте** и **источник привлечения пациента** с аналитикой.

---

## Июнь 2026

### ИИ-обзвон (новый модуль)
- **Новый раздел «ИИ обзвон»** в интерфейсе — доступен только роли «Владелец».
- **Голосовой режим в «Тест диалога»** — проверка сценария голосом; исправлена доступность сервиса `aicallrobot`.
- **Телефонная обвязка** — поднят контур Asterisk + мост **AudioSocket ⇄ WebSocket** для потоковой передачи аудио между АТС и голосовым роботом.
- **SIP-поля Novofon** добавлены в интеграции — реквизиты для исходящих ИИ-звонков.
- **Оркестратор кампаний** — управление кампаниями, сохранение результатов звонков и UI (этапы B4–B6).
- **Запуск `aicallrobot`** автоматизирован в скриптах `update.sh` / `deploy.sh`.

### Пациенты
- **Экспорт всей базы пациентов в XLS** — кнопка выгрузки в разделе «Пациенты».
- **Фикс возраста пациента** в расписании — корректный разбор даты рождения из 1Denta (формат ДД.ММ.ГГГГ).

## Июль 2026

### ИИ-обзвон и телефония
- **Тест-звонок на реальный номер** — разовый исходящий звонок для проверки; добавлен **живой транскрипт** разговора.
- **Рабочий простой диалог** тест-звонка (v1 + стоматологический сценарий).
- **Масштабирование до 20 одновременных звонков** в кампании.
- **Adaptive VAD** (детектор речи) для телефонии и **темп аудио 20 мс** в AudioSocket — устойчивее и естественнее распознавание/воспроизведение.
- **Стабилизация Asterisk ↔ Novofon:**
  - корректный CallerID в заголовке `From` и передача `P-Asserted-Identity` (иначе Novofon отбрасывал INVITE / не подставлял номер);
  - внешний адрес для NAT;
  - повторные попытки получения SIP-настроек + вывод HTTP-кода ошибки;
  - чтение ответа на `Originate` через AMI (а не события `FullyBooted`), вывод причины отклонения звонка;
  - базовый образ на Ubuntu 22.04 (в bookworm нет пакета asterisk);
  - AMI-пароль берётся из админки, Asterisk стартует через update/deploy.

### Расписание
- **Крупное обновление «ИИ обзвон и Расписание»** — кампании, скрипты, записи звонков, календарь.
- **Приём вебхуков SQNS от 1Denta** и корректные длительности записей.
- **Синхронизация удалений** из 1Denta, **обязательная услуга** при создании записи, корректные имена врачей, доработки UI сетки.
- **Отображение перерывов врачей** — вычисляются из свободных слотов 1Denta (позже временно скрыты до стабилизации).
- **Ховер-карточка записи** — разворачивается на месте плашки с сохранением её цвета; **красная линия текущего времени** по локальному часовому поясу.
- **Фиксы устойчивости:**
  - несуществующая таймзона `Asia/Ulan_Ude` роняла страницу расписания — исправлено;
  - гонка с вебхуком 1Denta при создании записи давала ошибку 500;
  - понятное сообщение об ошибке `SlotUnavailableError`;
  - нормализация телефона при создании визита в 1Denta;
  - признак онлайн-записи услуг берётся из `/api/v2/booking/service`.

### Интеграция с 1Denta
- **Почасовая авто-синхронизация**, фикс блокировок входа (троттлинг авторизации) и проблемы «Неизвестного пациента».
- **Статус синхронизации в «Настройках»** — отображается ход и **текст ошибки** синхронизации.

### Боты, коммуникации и лояльность
- **Меню пациента в ботах + бонусная программа** (Telegram/Max) — первая версия раздела бонусов.
- **Чаты ботов в «Коммуникациях»**, кликабельные ссылки в уведомлениях, поле «представитель ребёнка» в карточке пациента.
- **Разделители дат в переписке** (как в Telegram/Max).
- **Онбординг и help в ботах**, скрытие служебных сообщений бота из ленты чата, слоты расписания по 5 минут.
- **Авто-регистрация Telegram-webhook** при сохранении токена; **регистрация команд Telegram** при старте бэкенда.
- **Матч пациента по телефону** с нормализацией форматирования; не падать при создании, если 1Denta вернула существующего клиента.
- **Исправлена грамматика** названия клиники в разделе Help бота.

### Реалтайм
- **Живые счётчики непрочитанного, колокольчик уведомлений и браузерные пуши** для новых сообщений и лидов.

### Инфраструктура и деплой
- **Отдача `/static` через nginx** + постоянный том для загруженных файлов (аватары, скриншоты).
- **Ограничение объёма docker-логов** и правильный размер пула БД — устранены ошибки входа из-за переполнения диска.
- **Фиксы миграций Alembic** — слишком длинный `revision id 0023` (>32 символов) ломал `alembic upgrade`.

## Август 2026

### Телефония: второй провайдер — Ростелеком «Виртуальная АТС»
- **Переключатель провайдера телефонии Novofon / Ростелеком** — активный провайдер выбирается в «Настройках»; для пользователя «Контроль звонков» и «Коммуникации» работают одинаково.
- Интеграция приведена к **официальному API v7.5** (подписанные запросы `X-Client-Sign`, события `call_events`, асинхронная выгрузка истории вызовов, карточка звонящего).
- **Доверие сертификату API ВАТС** — поддержка сертификата «Russian Trusted CA»: вставка PEM в настройках + флаг `PARTIAL_CHAIN` (иначе ошибка «self-signed certificate in chain»); аварийный тумблер отключения проверки SSL.
- Уточнения по получению **SIP** (нужен только для ИИ-обзвона) в документации и подсказках интерфейса.

### ИИ-обзвон
- **fish.audio как альтернативный синтез речи (TTS)** — снижение задержки ответа робота; добавлена модель **S2.1 Pro** и назначена по умолчанию. Провайдер и голос выбираются на уровне кампании.
- **Провайдер-нейтральный тест-звонок** и **удаление кампании**.

### Расписание и контроль скриптов
- **Ручная длительность приёма** — редактируется в карточке; влияет на высоту блока в сетке и не перезаписывается синхронизацией 1Denta.
- **Метки времени** в сетке и **пагинация звонков** (по 20) при выборе звонка для сравнения со скриптом.

### Пациенты и аналитика
- **Источник привлечения пациента** (`referral_source`) — «откуда узнал о клинике» (Рекомендации, 2ГИС, Яндекс Карты, ПроДокторов, реклама и т.д.), отдельно от «канала обращения». Редактируется в карточке и при создании; список значений настраивается в «Настройках».
- **Аналитика по источникам и первичным пациентам** — новые отчёты «Источники обращений» и «Первичные пациенты» (разбивка взрослые/дети и по дням).
- **Фикс миграций** — устранено ветвление heads (миграция referral_source встроена в цепочку после 0027).

### Коммуникации: канал ВКонтакте
- **Интеграция ВКонтакте** — приём сообщений сообщества (vk.com) через Callback API и ответы через `messages.send`. Двусторонняя переписка ведётся из DentaFlow; отдельный канал «ВКонтакте» (не путать с мессенджером Max).

### Бонусная программа
- **Правила начисления баллов в боте** — в разделе «🎁 Бонусная программа» показываются баланс (с корректным склонением), правила начисления, реферальный код и история.
- **ИИ-ассистент обучен бонусам** — отвечает на вопросы о баллах и реферальном коде из описания программы, а не отправляет звонить в клинику; тон ассистента сделан более тёплым.

### Настройки
- **Кнопка «Сохранить» в каждом блоке интеграций** — сервисы сохраняются и проверяются по отдельности.
- **Новые блоки интеграций** — Ростелеком (ВАТС), ВКонтакте (Callback API), fish.audio (синтез речи), редактируемый список источников привлечения.

### Документация
- Обновлены `ARCHITECTURE.md` и `docs/admin-guide.md` под текущее состояние системы (телефония, ВКонтакте, fish.audio, источники привлечения, бонусы, ручная длительность приёма и др.).
