# Инструкция для роли «Маркетолог» — DentaFlow

> **Роль «Маркетолог»** — сотрудник, отвечающий за привлечение и удержание пациентов: источники и каналы, акции и скидки, подарочные сертификаты, бонусная программа, работа с базой (сегменты для обзвонов и рассылок), анализ эффективности.
>
> Актуально на: **сентябрь 2026**. Описание операционных разделов (расписание, звонки, задачи и т. д.) — в [инструкции администратора](admin-guide.md); здесь — то, что важно маркетологу, и отличия в правах.

## Доступ и права роли

Маркетолог видит в меню **все разделы, кроме «ИИ обзвон»**:

| Раздел | Доступ маркетолога |
|---|---|
| Обзор, Расписание, Пациенты, Карточка пациента | Полный (просмотр и работа) |
| Контроль звонков, Контроль скриптов | Полный |
| **Аналитика**, **Отчёты** | Полный (в отличие от администратора) |
| Заявки, Коммуникация, Воронка, Задачи | Полный |
| **Маркетинг** (скидки, сертификаты) | Полный: создание, изменение, удаление |
| **Бонусная программа** | Статистика, модерация отзывов, рейтинги, ручные начисления в карточке пациента. **Сохранение настроек программы — только Владелец/Управляющий** |
| Справочники | Просмотр, синхронизация, переименование врача |
| Сотрудники | Просмотр сотрудников и врачей, переименование врача. Управление сотрудниками — у Владельца/Управляющего, графики врачей — у Владельца/Управляющего/Администратора |
| **Настройки** | Открыты; маркетологу важны источники пациентов, автосоздание лидов, тексты и база знаний ботов (см. §10). Технические интеграции меняйте только по согласованию с владельцем |
| ИИ обзвон | **Недоступен** |

Общие элементы интерфейса (сворачиваемое меню, мобильное меню-«бургер», глобальный поиск **Ctrl+K / ⌘K**, колокольчик уведомлений, браузерные push-уведомления) описаны в [инструкции администратора](admin-guide.md#навигация-и-общие-элементы-интерфейса).

## 1. Обзор — ежедневный контроль воронки и источников

Страница `/`. Переключатель **День / Неделя / Месяц**.

Что смотреть маркетологу:
- **KPI:** Новые лиды, Записи, Подтверждено, Неявки, **Потеряно**, Выручка — динамика притока и потерь за период;
- **Воронка пациентов** — где «застревают» пациенты (количество и % по этапам);
- **Источники лидов** — источник, число лидов и конверсия по каждому каналу;
- **Баннер ИИ-помощника** — автоматические выводы по данным; «Обновить» — свежий анализ.

---

## 2. Аналитика (`/analytics`)

Вверху — **общий фильтр периода** для всех блоков: **Неделя** (со стрелками перехода между неделями) или **Месяц**.

**Карточки:**
- **Выручка за период**
- **Средний чек**
- **Новых пациентов**
- **Конверсия в визит** (пришли / записались)

**Блоки:**
- **Выручка по дням** — график.
- **Показатели по первичным пациентам** — пациенты, у которых **самый ранний визит попал в период**: всего первичных, **взрослые** и **дети** (по дате рождения), график по дням (столбцы взрослые/дети). Главный показатель эффективности привлечения.
- **Источники обращений** — сколько пациентов пришло из каждого **источника привлечения** («откуда узнал о клинике») за период: источник, пациенты, доля. Основа для оценки рекламных каналов (2ГИС, Яндекс Карты, ПроДокторов, блогеры, реклама и т. д.).
- **Популярность услуг** — услуга, количество, выручка, доля.

> Качество отчёта «Источники обращений» зависит от того, насколько аккуратно администраторы заполняют поле «Источник» у пациентов (см. §5).

## 3. Отчёты (`/reports`)

Период задаётся датами «с … по …».
- **Карточки:** Выручка, Записей, Новых пациентов, Повторных.
- **ИИ-Советник** — рекомендации по данным периода («Обновить рекомендацию»).
- **Выручка по дням**, **Популярные услуги**, **Нагрузка врачей** (записи, завершено, выручка).

## 4. Пациенты: сегменты, фильтры, выгрузки

Раздел `/patients`.

### 4.1 Списки и аналитика базы (кнопка «Списки»)

Готовые сегменты, которые ИИ строит по истории визитов в 1Denta, — основа для реактивации, обзвонов и рассылок:

| Список | Кто попадает |
|---|---|
| **Незавершённые планы лечения** | Были на лечении, но план не завершён и нет записи на продолжение |
| **Нужна гигиена 6+ мес** | Последняя профгигиена была более 6 месяцев назад |
| **Несостоявшиеся консультации** | Не записались или записались, но так и не пришли ни разу |
| **Не трогать** | Ручной стоп-лист: пациенты, которых нельзя включать в обзвоны и рассылки. Автоматически исключаются из остальных списков |

Для каждого списка:
- число пациентов, статус расчёта и время последнего обновления;
- **«Обновить»** — пересчёт в фоне (прогресс «обработано X из Y»). Пациенты, по которым данные не менялись, повторно не анализируются — пересчёт быстрый и экономный;
- **«Сбросить»** — если расчёт завис;
- **«Открыть»** — список пациентов с **причиной включения**, телефоном, последним визитом и выручкой;
- **«Excel»** — выгрузка списка для обзвона/рассылки.

В «Не трогать» пациента добавляют вручную (поиск по имени или телефону) и убирают кнопкой «Убрать из списка». Перед любой рассылкой проверяйте, что стоп-лист актуален.

### 4.2 Фильтры базы (кнопка «Фильтры»)

Комбинируйте для ручных сегментов:
- пол; **канал** (Telegram / Сайт / Звонок / Max / Реферал); **тип пациента** (Новые / Постоянные / Отказавшиеся / Потенциальные / Остальные); визиты (Посетили / Не посетили);
- **сумма продаж** и **количество визитов** (от–до);
- **день рождения** (диапазон — для поздравительных акций), **последнее посещение** (для реактивации «спящих»), **дата добавления в систему** (когорты).

### 4.3 Выгрузка всей базы

**«Скачать базу»** — Excel с тремя листами: «Пациенты» (контакты и карточка из 1Denta), «Посещения» (вся история визитов), «Услуги» (купленные услуги). Подходит для глубокого анализа в Excel/BI.

### 4.4 Карточка пациента

Полезное маркетологу: **источник привлечения**, канал обращения, LTV, статистика визитов и выручки, вкладка **«Бонусы»** (баланс, реферальный код, история начислений), **ИИ-анализ** (риски ухода, рекомендации).

## 5. Источник привлечения пациента

У каждого пациента есть два разных признака:
- **Канал обращения** — технически откуда пришло обращение (Telegram, звонок, сайт, Max, реферал);
- **Источник (откуда узнал о клинике)** — маркетинговая атрибуция: Рекомендации, 2ГИС, Яндекс Карты, ПроДокторов, Блогеры, Инстаграм, ВК, Реклама в интернете, Билборд, Реактивация, Сайт и т. д.

Источник выбирается при создании пациента и в шапке карточки (сохраняется сразу). При создании пациента из сделки он подставляется из заявки.

**Список источников редактируете вы** — «Настройки → Клиника → Источники пациентов» (добавить, удалить). Новые каналы продвижения добавляйте до запуска кампании, чтобы администраторы сразу могли их отмечать, а отчёт «Источники обращений» показал результат.

## 6. Маркетинг: скидки, промокоды, сертификаты

Раздел `/marketing`.

### 6.1 Скидки и бонусы

**«Новая скидка»** — поля:
| Поле | Значение |
|---|---|
| Название* | Например, «Скидка на первичный приём» |
| Тип | **Процент %**, **Фиксированная ₽** или **Бонусные баллы** |
| Значение | Размер скидки / число баллов |
| Промокод | Например, `SUMMER25` — для отслеживания конкретного канала или кампании |
| Применяется к | Все услуги / Новые пациенты / Повторные пациенты |
| Действует с / по | Срок акции (пусто — бессрочно, «∞») |
| Мин. сумма ₽ | Порог чека |
| Макс. использований | Лимит (пусто — без ограничений) |
| Описание | Условия для сотрудников |

Таблица показывает тип, размер, промокод, срок и **счётчик использований** (N / лимит). Фильтр: Все / Активные / Неактивные. В строке: **включить/выключить** (акцию можно приостановить без удаления), редактировать, удалить.

> Совет: заводите отдельный промокод на каждый канал (блогер, листовка, таргет) — счётчик использований покажет, какой канал сработал.

### 6.2 Подарочные сертификаты

Сводка: **Активных**, **Всего**, **Остаток на активных** (₽ — обязательства клиники). Фильтр: Все / Активные / Использованные / Истекшие / Отменённые.

**«Новый сертификат»:** код (пусто — сгенерируется автоматически), номинал ₽*, получатель (имя, телефон, email), кем куплен, действует с/по*, примечание.

Действия: **«Скопировать код»**, **«Погасить»** (использован), **«Отменить»**, **«Удалить»**.

Скидки и сертификаты, заведённые в 1Denta, подтягиваются в DentaFlow при ночной синхронизации.

## 7. Бонусная программа и реферальная система

Раздел `/loyalty`.

### 7.1 Правила программы (вкладка «Настройки»)

| Параметр | Описание |
|---|---|
| Начисление за оплату | **Фиксированно** (N баллов за каждые X ₽) или **процент от суммы** оплаченного визита |
| Баллы за рекомендацию | Начисляются владельцу реферального кода за нового пациента |
| Баллы за отзыв | За скриншот отзыва на площадке (после модерации) |
| Баллы за видеоотзыв | По умолчанию 2000, начисляются вручную после проверки |
| Оплата баллами | Включение, **курс балла** (сколько ₽ скидки даёт 1 балл), **лимит** (максимальная доля суммы визита, которую можно оплатить баллами, %) |

Эти правила автоматически показываются пациентам в ботах (раздел «🎁 Бонусная программа») и известны ИИ-ассистенту.

> **Сохранять изменения правил может только Владелец или Управляющий.** Маркетолог видит настройки и готовит предложения по ним; при попытке сохранить появится «Не удалось сохранить».

### 7.2 Статистика

Активных участников, всего начислено баллов, начислений за рекомендации, отзывов на проверке; **баллы по типам действий**: покупки, рекомендации, отзывы, видеоотзывы, оплата баллами, ручные корректировки. Позволяет оценить, какие механики работают.

### 7.3 Отзывы (модерация)

Пациенты отправляют скриншоты отзывов через бота («📤 Отправить скриншот отзыва»). Во вкладке «Отзывы» (фильтр: Все / На проверке / Одобренные / Отклонённые):
- **«Одобрить»** — система предложит количество баллов (по умолчанию из настроек) и начислит их;
- **«Отклонить»** — с подтверждением.

Регулярно разбирайте очередь «На проверке» — быстрая награда мотивирует оставлять отзывы.

### 7.4 Рейтинги

**Топ по баллам** и **Топ по рекомендациям** среди пациентов — кандидаты в амбассадоры, на персональные предложения и розыгрыши.

### 7.5 Реферальная система

- У каждого пациента есть **реферальный код** (вкладка «Бонусы» в карточке — «Сгенерировать»/«Скопировать»; пациент видит его в боте).
- При создании нового пациента в поле **«Реферальный код пригласившего»** указывается код — владельцу кода баллы начисляются автоматически, начисление связано с именем приведённого пациента.
- Свой собственный код пациент использовать не может; при выключенной программе баллы не начисляются (пациент создаётся, система покажет предупреждение).

### 7.6 Ручные начисления

В карточке пациента → «Бонусы»: **«За рекомендацию»**, **«За отзыв»**, **«Видеоотзыв»**, **«Корректировка»** (в т. ч. отрицательная) — с комментарием, который попадает в историю начислений. Используйте для акций («+500 баллов за участие»).

## 8. Лиды: заявки, чаты, воронка

- **Заявки** (`/communications`) — формы с сайта (Тильда) и звонки. Телефон из формы всегда переносится в заявку. Кнопка «Добавить лид в воронку CRM» создаёт сделку с данными и ИИ-анализом заявки.
- **Коммуникация** (`/chats`) — чаты Telegram, Max, ВКонтакте; кнопка «В воронку».
- **Воронка** (`/pipeline`) — этапы, канбан/таблица, у сделки — канал и **причина потери** (анализируйте причины отказов по закрытым ✗ сделкам).
- **Автосоздание лидов** — «Настройки → Интеграции → Автосоздание лидов из заявок»: выберите каналы (Сайт, Телефония, Telegram, Max, ВКонтакте) и этап воронки — новые заявки будут сами превращаться в сделки.
- Необработанная более 15 минут заявка порождает уведомление в колокольчике — полезно для контроля скорости реакции на рекламный трафик.

Подробнее о работе с разделами — в [инструкции администратора, §8–10](admin-guide.md#8-заявки-communications).

## 9. Боты как маркетинговый канал

Telegram- и Max-боты клиники:
- **главное меню**: запись, вопрос ИИ-ассистенту, «Мои визиты и оплаты», «Бонусная программа», смена номера, связь с менеджером, помощь;
- **ИИ-ассистент** отвечает по базе знаний клиники в тёплом тоне, мягко выявляет потребность одним уточняющим вопросом; **цены называет только диапазоном «от … до …»** (по прайсу из 1Denta) и подчёркивает, что точная стоимость определяется на приёме;
- рассказывает о **бонусной программе** и реферальном коде;
- принимает **скриншоты отзывов** на модерацию;
- за 24 часа напоминает о визите — снижает неявки.

Сообщения сообщества **ВКонтакте** приходят в «Коммуникацию» (ручной чат, без ИИ-ответов).

## 10. Настройки, полезные маркетологу

Раздел `/settings`:

| Где | Что настроить |
|---|---|
| **Клиника → Источники пациентов** | Список вариантов «откуда узнал о клинике» |
| **Интеграции → Автосоздание лидов из заявок** | Каналы и этап воронки для автолидов |
| **Интеграции → Настройки ботов (общие)** | Название клиники для ботов, приветственное сообщение |
| **Интеграции → База знаний бота** | Файлы с информацией об услугах, акциях, FAQ — на них опирается ИИ-ассистент |
| **Интеграции → Telegram / Max** | Включение ИИ-ответов, системный промпт (тон и правила ассистента) |
| **Интеграции → Форма на сайте / Тильда** | Адрес вебхука для формы на сайте |

> Остальные блоки «Интеграций» (телефония, 1Denta, OpenAI, ключи и токены) — технические. Изменяйте их только по согласованию с владельцем: ошибка может остановить приём звонков, заявок или синхронизацию. Вкладка «Мотивация» (баллы администраторов) сохраняется только Владельцем/Управляющим.

## Типовые сценарии

**Запуск акции с промокодом**
1. «Маркетинг → Скидки и бонусы» → «Новая скидка»: тип, размер, промокод, срок, «Применяется к».
2. При необходимости добавьте канал продвижения в «Настройки → Клиника → Источники пациентов».
3. Загрузите описание акции в «Базу знаний бота», чтобы ИИ-ассистент мог о ней рассказать.
4. По окончании — сравните счётчик использований промокода и «Источники обращений» в «Аналитике».

**Реактивация базы**
1. «Пациенты → Списки» → «Обновить» нужные списки (гигиена 6+ мес, незавершённое лечение, несостоявшиеся консультации).
2. Проверьте стоп-лист «Не трогать».
3. «Excel» — выгрузка для обзвона/рассылки; при необходимости поставьте администраторам задачи «Перезвонить».
4. Результат — в «Аналитике» (первичные/повторные, выручка) и источник «Реактивация» у вернувшихся пациентов.

**Сбор отзывов**
1. Расскажите пациентам (в клинике, в боте, в рассылке) о баллах за отзыв и видеоотзыв.
2. Разбирайте «Бонусная программа → Отзывы → На проверке»; видеоотзывы начисляйте в карточке пациента.
3. Следите за динамикой в «Статистике» (за отзывы / видеоотзывы).

**Оценка рекламного канала за месяц**
1. «Аналитика» → «Месяц»: «Источники обращений» и «Показатели по первичным пациентам».
2. «Обзор» → «Источники лидов»: конверсия лидов по каналам.
3. «Воронка»: причины потерь по закрытым ✗ сделкам.
