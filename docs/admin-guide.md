# Инструкция для роли «Администратор» — DentaFlow

> **Роль «Администратор»** — операционный сотрудник клиники (ресепшн, кол-центр). Ведёт расписание, пациентов, заявки и переписку, воронку и задачи; работает с бонусной программой пациентов, скидками и сертификатами. Финансовая аналитика, отчёты, настройки системы, управление учётными записями сотрудников и ИИ-обзвон **недоступны**.
>
> Актуально на: **сентябрь 2026**. Инструкция для роли «Маркетолог» — в [`docs/marketer-guide.md`](marketer-guide.md).

## Навигация и общие элементы интерфейса

Боковое меню (десктоп) состоит из блоков:

**Основное:**
- Обзор
- Расписание
- Пациенты
- Контроль звонков
- Контроль скриптов

**Коммуникации:**
- Заявки — обращения с сайта и из телефонии
- Коммуникация — чаты Telegram, Max и ВКонтакте
- Воронка
- Задачи

**Прочее:**
- Маркетинг
- Бонусная программа
- Справочники
- Сотрудники

Пункты **Аналитика**, **Отчёты**, **Настройки** и **ИИ обзвон** для роли «Администратор» скрыты; при переходе по прямой ссылке система возвращает на «Обзор».

**Сворачивание меню.** Кнопка сворачивания превращает меню в узкую полосу с иконками и подсказками при наведении. Состояние запоминается между сессиями. На странице «Расписание» меню сворачивается автоматически, чтобы сетка заняла всю ширину.

**Живые счётчики в меню:**
- **«Задачи»** — красный бейдж с числом активных (невыполненных) задач;
- **«Коммуникация»** — число непрочитанных чатов.

Счётчики обновляются в реальном времени (и дополнительно раз в минуту). В свёрнутом меню они показываются компактно на иконке.

**Мобильная версия.** Нижняя панель навигации заменена **боковым меню-«бургером»**: кнопка ☰ слева в шапке открывает выдвижную панель со **всеми** доступными пунктами меню и теми же счётчиками.

**Шапка страницы:**
- **Поиск** (кнопка «Поиск» или сочетание **Ctrl+K / ⌘K**) — глобальный поиск по пациентам, сделкам и коммуникациям; клик по результату открывает нужную карточку.
- **Колокольчик уведомлений** — список событий с иконкой по типу: новое сообщение в чате, новый лид/заявка, пропущенный звонок, необработанная заявка (висит без ответа более 15 минут), застрявшая сделка, сигнал ИИ, **день рождения** сотрудника/врача, **«неверный номер»** (пациент в боте сообщил, что номер привязан к чужой карте). Клик по уведомлению открывает нужный чат/заявку/раздел. Есть кнопки «Прочитать все» и «Очистить», отдельное уведомление можно удалить.
- **Браузерные push-уведомления** — после входа браузер спросит разрешение; если его дать, о новых сообщениях и заявках придёт системное уведомление, даже когда вкладка DentaFlow не активна.
- **«Выйти»** — выход из системы.

## 1. Обзор (`/`)

Вверху — переключатель периода **День / Неделя / Месяц** и даты выбранного периода.

**Баннер ИИ-помощника** — советы по данным клиники. Кнопка **«Обновить»** запрашивает свежий анализ.

**KPI-карточки** (пересчитываются при смене периода):
- Новые лиды
- Записи
- Подтверждено
- Неявки
- Потеряно
- Выручка

Ниже в двух колонках:
- **Воронка пациентов** — столбиковая диаграмма по этапам (количество и %);
- **Источники лидов** — таблица: источник, лиды, конверсия.

Нижний ряд:
- **Загрузка врачей** — имя врача, число приёмов, % загрузки;
- **Рейтинг администраторов** — колонки **Место** (🥇/🥈/🥉 для топ-3), **Администратор**, **Выполнено задач**, **Баллы**. Баллы начисляются автоматически за выполненные задачи и другие действия. Если баллов ещё нет — «Баллы ещё не начислялись. Рейтинг появится после первых выполненных задач.»

| Элемент | Действие |
|---|---|
| День / Неделя / Месяц | Меняет период для всех KPI и графиков |
| «Обновить» в баннере ИИ | Запрашивает новый ИИ-анализ |

## 2. Расписание (`/schedule`)

Страница открывается сразу с сеткой расписания (статистических карточек и баннера ИИ больше нет). Главное меню при открытии автоматически сворачивается.

**Левая панель** (сворачивается кнопкой «Свернуть» в узкую полосу; на телефоне по умолчанию свёрнута):
- мини-календарь: клик по дате — переход на день, стрелки листают месяцы, кнопка «Сегодня»;
- кнопка **«Добавить запись»**;
- фильтр **«Врач»** (все врачи или один);
- фильтр **«Статус»**: Подтверждено, Не подтверждено, Пришёл, Завершено, Отменено, Не явился;
- счётчик **«Визиты: N»**.

> Ручной кнопки «Синхронизировать» в расписании больше нет: изменения из 1Denta приходят **мгновенно через вебхук** (создание, перенос, отмена, удаление визита), а раз в час дополнительно выполняется страховочная синхронизация.

**Сетка расписания:**
- заголовок — дата и день недели, стрелки на соседний день;
- **колонки врачей**: аватар, имя, специализация, число записей. Показываются врачи с записями на этот день **и врачи, которые по графику работы (раздел «Сотрудники») работают в этот день**, даже если записей ещё нет;
- временная шкала 09:00–20:00, блоки пропорциональны длительности; строка врачей закреплена сверху, колонка времени — слева;
- **красная линия «сейчас»** на сегодняшнем дне (по часам вашего компьютера);
- значок **①** у первичных пациентов;
- **цвета статусов**: зелёный — пациент пришёл/визит завершён, фиолетовый — подтверждён, оранжевый — запись не подтверждена, красный — отменён, серый — не явился;
- **серые заштрихованные зоны** — нерабочее время врача по графику (выходной, до/после смены, перерывы). В них нельзя поставить запись и нельзя перетащить приём.

**Ховер-карточка.** При наведении на запись плашка увеличивается на месте и показывает время и длительность, ФИО и возраст, ① для первичных, телефон, услугу, комментарий и статус.

**Быстрое создание записи.** При наведении на свободное время в колонке врача появляется рамка «Новая запись» (шаг 5 минут); клик открывает форму с уже подставленными врачом, датой и временем.

**Перенос перетаскиванием.** Запись можно перетащить на другое время или к другому врачу — рядом с курсором показывается новое время. Перенос в нерабочее время врача запрещён.

**Окно «Новая запись»:**
- имя пациента и телефон (обязательно; телефон проверяется как российский номер из 11 цифр);
- врач;
- **услуга (обязательно)** — список содержит только услуги, открытые для онлайн-записи в 1Denta и доступные выбранному врачу (при смене врача неподходящая услуга сбрасывается);
- **дата визита и время «с … по …»** — длительность считается автоматически из интервала;
- комментарий.

Запись создаётся **сначала в 1Denta**; если 1Denta отказывает (время занято или вне графика), выводится понятная ошибка, а запись не создаётся. Если время выходит за график врача, форма заранее предупреждает об этом.

**Окно «Детали записи»** (клик по блоку):
- **Пациент** (вверху): ФИО, телефон, дата рождения, пол, канал, тип (первичный), визитов, выручка, средний чек, последний визит; для детей — **представитель** (ФИО и телефон);
- кнопка **«Пациент пришёл»** — быстрая отметка явки;
- **статус** — меняется из выпадающего списка;
- **врач и услуга** — редактируются из выпадающих списков;
- **время визита «с … по …»** — редактируется; дата и время начала синхронизируются с 1Denta. Длительность хранится локально (1Denta не принимает её через API) и **не перезаписывается** синхронизацией;
- **комментарий** — синхронизируется с 1Denta;
- блок **«Финансы»**: сумма по прайсу, скидка (₽), сумма оплаты (₽), кнопка **«Оплатить»**;
- блок **«Оплата баллами»** (если включён в бонусной программе): показан баланс пациента, поле «Списать баллов», кнопка «Максимум». Система не даст списать больше баланса и больше установленного лимита (% от суммы визита); «Скидка баллами» и «Сумма оплаты» пересчитываются автоматически. Повторное сохранение заменяет прошлое списание, а не добавляет новое;
- **«Удалить запись»** — с подтверждением, удаляется и в 1Denta;
- блок «Данные 1Denta» (номер визита, филиал и т. п.).

| Элемент | Действие |
|---|---|
| Мини-календарь / «Сегодня» / стрелки | Переход по датам |
| «Добавить запись» или клик по свободному слоту | Создание записи |
| Перетаскивание блока | Перенос записи по времени или к другому врачу |
| Фильтры «Врач» / «Статус» | Фильтрация сетки |
| Клик по блоку | Детали записи, оплата, списание баллов, удаление |

## 3. Пациенты (`/patients`)

Вверху — поиск (имя, телефон, email) со счётчиком «N пациентов» и кнопки:
- **«Фильтры»** — панель расширенных фильтров (показывает число применённых);
- **«Списки»** — панель «Списки и аналитика базы» (см. ниже);
- **«Скачать базу»** — выгрузка всей базы в Excel (`.xlsx`) из трёх листов: «Пациенты», «Посещения», «Услуги»;
- **«Новый пациент»** — форма создания пациента.

**Панель фильтров:**
- пол; источник (канал): Telegram / Сайт / Звонок / Max / Реферал; тип пациента: Новые / Постоянные / Отказавшиеся / Потенциальные / Остальные; визиты: Посетили / Не посетили;
- сумма продаж, ₽ (от–до); количество визитов (от–до);
- день рождения, последнее посещение, дата добавления (диапазоны дат);
- кнопки «Применить» и «Сбросить».

**Таблица:** пациент (аватар, имя, email), телефон, источник, последний визит, LTV (зелёный ≥ 70, жёлтый ≥ 40, красный < 40), выручка. Пагинация по 20. Клик по строке — карточка пациента.

**Списки и аналитика базы.** Готовые списки пациентов, которые ИИ формирует по истории визитов из 1Denta:
- **Незавершённые планы лечения** — был на лечении, но план не завершён и записи на продолжение нет;
- **Нужна гигиена 6+ мес** — последняя профгигиена более 6 месяцев назад;
- **Несостоявшиеся консультации** — не записывались или были записаны, но так и не пришли;
- **Не трогать** — ручной список пациентов, которых нельзя включать в обзвоны и рассылки (исключаются из остальных списков).

У каждого списка — число пациентов, статус расчёта («Не рассчитан / В очереди / Идёт анализ — обработано X из Y / Готово / Ошибка»), время обновления и кнопки **«Обновить»** (пересчёт в фоне; уже проанализированные пациенты без изменений повторно не анализируются), **«Сбросить»** (если расчёт завис), **«Открыть»** (список с причиной включения и пагинацией) и **«Excel»** (выгрузка). В список «Не трогать» пациента добавляют вручную (поиск по имени или телефону) и убирают кнопкой «Убрать из списка».

**Форма «Новый пациент»:** ФИО, дата рождения, пол; контакты (телефон, доп. телефон, email); адрес; документы (паспорт, СНИЛС, ИНН, полис ОМС); примечание; **канал обращения**; **источник (откуда узнал о клинике)**; **реферальный код пригласившего**; переключатель **«Передать в 1Denta»**.
Если указан реферальный код, владельцу кода автоматически начисляются баллы за рекомендацию. Если код не найден, это свой код пациента или программа выключена — пациент всё равно создаётся, а система показывает предупреждение.

| Элемент | Действие |
|---|---|
| Поиск | Мгновенная фильтрация |
| «Фильтры» → «Применить»/«Сбросить» | Расширенная фильтрация |
| «Списки» | ИИ-списки пациентов, выгрузка в Excel |
| «Скачать базу» | Выгрузка всей базы в Excel |
| «Новый пациент» | Создание пациента (с реферальным кодом) |
| Клик по строке | Карточка пациента |

## 4. Карточка пациента (`/patients/:id`)

Кнопка **«← Пациенты»** — возврат к списку.

**Шапка:** имя, телефон, email, канал обращения, дата рождения, метка «Новый»; финансовые данные из 1Denta (баланс, депозит, персональная скидка).
- **«Источник (откуда узнал о клинике)»** — выпадающий список (Рекомендации, 2ГИС, Яндекс Карты, ПроДокторов, Блогеры, Инстаграм, ВК, Реклама в интернете, Билборд, Реактивация, Сайт и т. д.), сохраняется сразу. Это не то же самое, что канал обращения: канал — откуда технически пришло обращение, источник — откуда пациент узнал о клинике.
- **Представитель (для детей до 18 лет)** — ФИО родителя/опекуна, кем приходится, телефон; заполняется вручную (кнопка-карандаш «Изменить»). У детей рядом с именем показан возраст.
- Кнопки: **«Записать»** (новая запись в расписание), **«Создать сделку»** (сделка в воронке), **«Удалить»** (с подтверждением).

**Вкладки:**
1. **История визитов** — приёмы из 1Denta: дата, врач, услуга, статус, стоимость.
2. **Статистика** — всего визитов, завершено, отменено, неявок, врачей, услуг, суммарная выручка, средний чек, LTV, первый/последний визит.
3. **Бонусы** — баланс баллов, **реферальный код** (кнопки «Сгенерировать» и «Скопировать»), ручные начисления: **«За рекомендацию»**, **«За отзыв»**, **«Видеоотзыв»**, **«Корректировка»** (можно отрицательное число) — с необязательным комментарием; **история начислений** (покупка, рекомендация, отзыв, видеоотзыв, оплата баллами, корректировка).
4. **Коммуникации** — входящие/исходящие сообщения и звонки пациента.
5. **CRM** — сделки пациента в воронке.
6. **Задачи** — задачи по пациенту.

**Правая панель «ИИ-Анализ пациента»** — портрет пациента, риски, рекомендации. Запускается автоматически при открытии и кэшируется, пока данные пациента не изменились; «Обновить» запрашивает свежий анализ.

## 5. Контроль звонков (`/calls`)

> Работает с IP-телефонией **Новофон** или **Ростелеком «Виртуальная АТС»** (провайдер выбирает владелец в «Настройках»; для администратора раздел одинаков). Звонки поступают автоматически через вебхук, пропущенные создают задачу «Перезвонить».

**Карточки:** Всего звонков, Отвечено, Пропущено, % ответов.

**«История звонков»** — фильтры **Период** (3 / 7 / 14 / 30 дней) и **Статус** (Все / Отвечено / Пропущено), кнопка **синхронизации** истории с телефонией (после неё показывается итог «Синхронизировано: N звонков (пропущено дублей: M)»).

**Таблица:** дата и время, направление (входящий/исходящий), откуда, куда, длительность, статус (зелёный «Отвечен», красный «Пропущен»), кнопка **«Прослушать запись»**. На телефоне строки отображаются компактными карточками (номер + статус, вызываемый номер, дата · длительность).

**Особенности:**
- **Дедупликация.** Несколько событий АТС по одному звонку сводятся в одну строку; звонок отвеченный, только если линию действительно подняли.
- **Сверка при синхронизации.** Статус, длительность, направление и время приводятся к итоговым данным АТС.
- **Ростелеком.** Журнал звонков АТС формирует асинхронно: при синхронизации система сама дожидается файла (до ~75 секунд) и импортирует его. Если файл не успел сформироваться — будет сообщение, что журнал ещё формируется; повторите позже. Самые свежие звонки появляются в журнале АТС с задержкой, но в реальном времени всё равно приходят вебхуком.

## 6. Контроль скриптов (`/scripts`)

**Карточки:** Всего скриптов, Проанализировано, Средняя оценка (звонки).

**«Скрипты звонков»** — таблица (название, категория, дата, оценка) и кнопка **«Загрузить скрипт»**. В окне загрузки: название, категория, текст скрипта **или файл** (`.txt`, `.pdf`, `.docx`). В строке скрипта — кнопки **«Анализ»** (ИИ-оценка) и **«Удалить»**.

**Панель «ИИ-анализ скрипта»** — оценка, качество, полнота, сильные стороны, слабые места, рекомендации.

**«Отвеченные звонки»** (с записью, за 30 дней; по 20 на странице, «← Назад / Вперёд →») — у каждого звонка кнопка **«Расшифровать»**: запись переводится в текст и подставляется в блок сравнения. Если расшифровка не удалась (например, закончились средства на счёте распознавания), показывается понятная причина — расшифровку можно вставить вручную.

**«Сравнение звонка со скриптом»** — выберите скрипт, вставьте/получите расшифровку и нажмите **«Сравнить со скриптом»**. Результат: % соответствия, выполненные и пропущенные этапы, отклонения, рекомендации.

## 7. Каналы коммуникаций

Обращения поступают из Telegram-бота, Max-бота, сообщений сообщества ВКонтакте, телефонии и формы на сайте:
- **чаты** (Telegram, Max, ВКонтакте) — в разделе **«Коммуникация»** (§9);
- **звонки и заявки с сайта** — в разделе **«Заявки»** (§8).

### 7.1 Telegram-бот

AI-ассистент клиники в Telegram. **Главное меню** показывается кнопками в сообщении, а также доступно через меню команд (кнопка ≡ / «/»):

| Пункт меню / команда | Что делает |
|---|---|
| 📅 Записаться на приём (`/book`) | Пошагово собирает имя, телефон и описание проблемы; создаёт заявку для администратора |
| 💬 Задать вопрос (`/ask`) | AI-чат по базе знаний клиники: услуги, расписание, бонусная программа. Цены называет **только диапазоном «от … до …»** и всегда уточняет, что точная стоимость определяется на приёме |
| 📋 Мои визиты и оплаты (`/history`) | История визитов пациента с суммами (по номеру телефона) |
| 🎁 Бонусная программа (`/bonus`) | Баланс (с правильным склонением «балл/балла/баллов»), правила начисления из настроек (за оплату, рекомендацию, отзыв, видеоотзыв), реферальный код, последние операции, кнопка **«📤 Отправить скриншот отзыва»** |
| ☎️ Изменить номер телефона | Новый номер сохраняется в DentaFlow, у пользователя бота и **в 1Denta** |
| 📞 Связаться с менеджером (`/manager`) | Создаёт обращение с именем и номером клиента |
| ℹ️ Помощь (`/help`) | Описание всех возможностей бота |
| `/start` | Главное меню |

**Удобства для пациента:**
- кнопка **«📱 Поделиться номером»** на шаге ввода телефона;
- **бот запоминает имя и телефон** после первого сценария: при повторной записи или запросе менеджера заявка создаётся сразу, а кнопка «✏️ Указать другие контакты» позволяет их сменить;
- **несколько карт на один номер** (родитель и ребёнок, номер друга) — бот предлагает выбрать нужного пациента, выбор запоминается;
- кнопка **«🚫 Нет такого пациента»** — если номер оказался привязан к чужой карте; администратор получает уведомление «неверный номер» в колокольчике с номером и совпавшими картами — проверьте и исправьте телефон в карточке.

**Двусторонняя переписка.** Живой диалог клиента с менеджером попадает в «Коммуникацию»; администратор отвечает из DentaFlow — ответ приходит клиенту в Telegram. Пациент видит подтверждение «✉️ Получено, менеджер ответит вам здесь.»
Вопросы к AI-ассистенту («Задать вопрос») и ввод данных в сценариях в раздел не попадают — только диалог с менеджером.

**Напоминания.** За 24 часа до визита пациент, который пользовался ботом и оставил номер, получает напоминание (дата, время, врач, услуга) с кнопками «Перенести» и «Отказаться» (обе предлагают позвонить в клинику).

### 7.2 Max-бот

Аналог Telegram-бота в мессенджере Max: то же главное меню кнопками (запись, вопрос, визиты и оплаты, бонусы, смена номера, менеджер, помощь), выбор пациента по номеру, «Нет такого пациента», отправка скриншота отзыва, напоминания за 24 часа и двусторонняя переписка. Обращения помечаются каналом **Max**.

### 7.3 ВКонтакте (сообщения сообщества vk.com)

Отдельный от Max канал: сообщения в сообщество ВКонтакте попадают в «Коммуникацию» с пометкой **ВКонтакте**, имя берётся из профиля ВК. Это **ручной чат** — автоответов AI-ассистента нет, отвечает администратор из DentaFlow. Подключение настраивает владелец/управляющий в «Настройках → Интеграции → ВКонтакте».

### 7.4 Телефония (Новофон / Ростелеком)

| Событие | Действие системы |
|---|---|
| Входящий звонок | Фиксируется в «Контроле звонков» и «Заявках»; если номер есть в базе — привязывается к пациенту |
| Пропущенный звонок | Задача «Перезвонить» (высокий приоритет) + уведомление в колокольчике |
| Отвеченный звонок | Фиксируется с длительностью, запись доступна для прослушивания и расшифровки |
| Исходящий звонок | Фиксируется в истории |

При звонке пациента из базы АТС Ростелекома может показывать его имя на экране телефона администратора.

### 7.5 Форма на сайте (Тильда)

Заявки с формы сайта приходят в «Заявки» с пометкой **Сайт**. Телефон из формы всегда переносится в текст заявки («Телефон: …»), даже если поле на сайте названо нестандартно; заявка привязывается к пациенту по любому формату записи номера. Даже при ошибке разбора заявка не теряется — сохраняется с исходными данными формы.

**Где взять логин и пароль:** личный кабинет **my.novofon.ru** → **Телефония → Пользователи АТС** → нужный пользователь → вкладка **«Основные настройки»**.

## 8. Заявки (`/communications`)

Раздел для обращений **с сайта** и из **телефонии** (звонки, пропущенные звонки). Чаты мессенджеров вынесены в раздел «Коммуникация» (§9).

**Строка фильтров:** статусы **Все / Новые / В работе / Закрытые** со счётчиками; фильтр канала: Все каналы / Телефония / Сайт.

**Левая панель — список «Заявки · N»:** иконка канала (пропущенный звонок — красная), имя пациента (или «Новый контакт»), цветная точка статуса, канал, направление, время, превью (для звонка — длительность и номер, для сайта — текст формы), кнопка удаления.

**Правая панель — детали:** имя, канал, дата и время, содержимое; блок **«ИИ-анализ»** (резюме, рекомендуемое действие, теги) — если анализ есть.
- **«Добавить лид в воронку CRM»** — создаёт сделку с автозаполнением имени, телефона и заметок (содержимое заявки + ИИ-анализ); заявка переводится «В работу». После этого кнопка становится «Добавлено в воронку ✓» (состояние сохраняется после перезагрузки).
- **«Закрыть заявку»** — переводит заявку в «Закрытые».

Ссылка из уведомления (`/communications?comm=…`) сразу открывает нужную заявку.

## 9. Коммуникация — чаты (`/chats`)

Единое окно переписки с клиентами в **Telegram**, **Max** и **ВКонтакте**.

**Слева — список чатов:** непрочитанные сверху, затем по времени последнего сообщения. Непрочитанные выделены жирным и синей точкой; в шапке — счётчик «N новых». У строки — канал, направление, «сколько времени назад», превью; кнопка удаления при наведении.

**Справа — чат:**
- сообщения клиента слева, ответы сотрудников справа; между днями — разделители «Сегодня», «Вчера», «18 июля»;
- служебные автосообщения бота скрыты — видно только диалог клиента и оператора;
- поле ответа: **Enter** — отправить, **Shift+Enter** — новая строка; ответ уходит клиенту в его мессенджер;
- для очень старых обращений (до введения переписки) ответ недоступен — свяжитесь с клиентом по телефону.

**Кнопки над чатом:** **«В воронку»** (создать сделку из чата), **«Закрыть»** (закрыть обращение; при новом сообщении клиента чат снова станет непрочитанным).

Открытие чата переводит его в статус «В работе» и уменьшает счётчик непрочитанных в меню. Ссылка из уведомления (`/chats?comm=…`) открывает нужный чат.

## 10. Воронка (`/pipeline`)

**Настройка этапов** («Настроить этапы воронки» / «Скрыть настройку этапов»): перетаскивание (⠿) для порядка, двойной клик — переименование (Enter — сохранить, Esc — отмена), **добавление нового этапа**, **удаление этапа**, **«Удалить все сделки из этапа»**.

**Баннер ИИ-ассистента «Воронка»** — застрявшие сделки, горячие лиды, отказы, необработанные заявки.

**Панель управления:** «Добавить сделку», фильтр «Все ответственные» (активные администраторы и управляющие), в табличном виде — «Все этапы», сумма воронки «Воронка: N ₽», переключатель **Канбан / Таблица**.

**Канбан:** колонки этапов (Лист ожидания, Новые, Контакт, Переговоры, Записан, Лечение, Закрыто ✓, Закрыто ✗) со счётчиком и суммой; карточки перетаскиваются между колонками. Клик на счётчик пациентов открывает боковую панель пациентов этапа.

**Таблица:** пациент/сделка, услуга, врач, этап, сумма, удаление; пагинация по 20.

**Окно сделки** — вкладки **Основное** (название, этап, услуга, врач, канал, сумма, ответственный, **причина потери** для проигранных), **Задачи** (задачи по сделке, создание новой), **Заметки**, **История** изменений.

**«Новая сделка»:** название, имя пациента и телефон (обязательно), канал (Сайт, Телефон, ВКонтакте/MAX, Ручной ввод и др.), этап, услуга, врач, сумма, ответственный, заметки.

> Лиды могут создаваться в воронке **автоматически** из заявок выбранных каналов — это включает владелец/управляющий в «Настройках → Интеграции → Автосоздание лидов».

## 11. Задачи (`/tasks`)

**Фильтры:** **Все / Активные / Выполненные / Архив** (истёкшие автозадачи), счётчик «⚠ N просрочено», фильтр «Все ответственные».

**Кнопки:**
- **«+ Новая задача»** — тип (Перезвонить / Напоминание / Подтвердить визит / Другое), пациент (необязательно, поиск), название, срок (дата и время), ответственный (необязательно);
- **«Сгенерировать на сегодня»** — вручную создать задачи-обзвон для подтверждения визитов на завтра (если утренняя автогенерация не сработала); дублей не создаёт.

**Таблица:** чекбокс выполнения, задача (бейдж **⚡ Авто** у автозадач, у выполненной — дата и время выполнения), тип (в т. ч. **«День рождения»**), пациент (ссылка на карточку), исполнитель («Общая задача» у автозадачи без исполнителя), срок (красный — просрочено), статус (В работе / Просрочено / Выполнено / Истёк), удаление. Пагинация по 15.

**Массовое удаление:** отметьте задачи чекбоксами выделения (или «Выделить все»), затем **«Удалить выбранные (N)»** с подтверждением.

**Баллы.** За выполнение задачи исполнителю начисляются баллы (по умолчанию 10) — они формируют «Рейтинг администраторов» на «Обзоре» и в «Сотрудниках».

Расписание автоматических задач — в разделе [Автоматические процессы](#автоматические-процессы-что-система-делает-сама).

## 12. Маркетинг (`/marketing`)

## 13. Бонусная программа (`/loyalty`)

Четыре вкладки.

**Настройки** — просмотр правил программы: способ начисления за оплату (**фиксированно** — N баллов за каждые X ₽, или **процент от суммы** оплаченного визита), баллы за рекомендацию, отзыв и **видеоотзыв** (по умолчанию 2000), **оплата баллами** (курс балла в рублях и лимит — какую долю суммы визита можно оплатить баллами).
> Сохранять изменения настроек могут только **Владелец** и **Управляющий**; у администратора сохранение завершится ошибкой «Не удалось сохранить».

**Статистика** — активных участников, всего начислено баллов, начислений за рекомендации, отзывов на проверке; разбивка «Баллы по типам действий»: за покупки, за рекомендации, за отзывы, за видеоотзывы, оплата баллами, ручные корректировки.

**Отзывы** — модерация скриншотов отзывов, присланных пациентами через бота. Фильтр: Все / На проверке / Одобренные / Отклонённые. По отзыву на проверке:
- **«Одобрить»** — система спросит, сколько баллов начислить (подставляет значение из настроек), и начислит их пациенту;
- **«Отклонить»** — с подтверждением.
Имя пациента — ссылка на его карточку.

**Рейтинги** — «Топ по баллам» и «Топ по рекомендациям» среди пациентов.

**Как начисляются баллы:**
| Действие | Как начисляется |
|---|---|
| Оплаченный визит | Автоматически после оплаты (фиксированно или % — по настройке) |
| Рекомендация | Автоматически, если при создании нового пациента указан реферальный код пригласившего; либо вручную в карточке («За рекомендацию») |
| Отзыв (скриншот) | При одобрении во вкладке «Отзывы» или вручную в карточке («За отзыв») |
| Видеоотзыв | Вручную в карточке пациента после проверки («Видеоотзыв») |
| Корректировка | Вручную в карточке, можно отрицательное число |
| Оплата баллами | Списание в окне визита (блок «Оплата баллами») |

## 14. Справочники (`/directories`)

Вкладки **Услуги** (название, категория, длительность, цена, описание), **Врачи / Ресурсы**, **Товары** (название, цена). Справа — время последнего обновления; кнопка **«Обновить из 1Denta»** запускает синхронизацию и показывает итог («Данные обновлены» / «Частичное обновление» со счётчиками).

Данные редактируются в 1Denta; исключение — **имя врача/ресурса** можно поправить прямо здесь (иконка-карандаш «Изменить имя» при наведении). Ручное переименование не затирается синхронизацией.

## 15. Сотрудники (`/staff`)

Раздел открыт администратору.

- **Статистика:** всего сотрудников, администраторов.
- **Рейтинг администраторов** по баллам.
- **Таблица сотрудников:** имя, роль (Владелец / Управляющий / Администратор / Маркетолог), статус (Активен / Отключён), дата рождения, бейдж **«Без входа»** для сотрудников без доступа в систему. Добавлять, редактировать и удалять сотрудников может только Владелец/Управляющий.
- **Врачи** (из справочника 1Denta, без плейсхолдеров «Врач #N»): имя, специализация, дата рождения, график. Администратор может:
  - **переименовать** врача;
  - указать **дату рождения**;
  - задать **график работы**:
    - **недельный шаблон** (сворачиваемый): для каждого дня — рабочий/выходной, часы «с … по …» и **любое количество перерывов**;
    - **календарь по датам**: у каждой даты видно «по шаблону», «своё время» или «выходной»; клик по дате позволяет задать свои часы и перерывы, сделать выходным или вернуть к шаблону;
    - **быстрое заполнение**: применить шаблон к диапазону дат, сделать диапазон выходным, очистить диапазон, **«Повторять этот диапазон каждые N нед. до <даты>»** — для сменных/чередующихся графиков.

**Как график влияет на расписание:** нерабочее время врача закрашивается серым и блокирует запись и перенос; врачи, работающие в выбранный день, появляются в сетке даже без записей. Если у врача график не задан — ограничений нет.

**Дни рождения.** За день до дня рождения сотрудника или врача администраторы получают уведомление «Завтра день рождения 🎂» и задачу «Поздравить с днём рождения: …».

## Автоматические процессы (что система делает сама)

Время указано по Москве (клиника в Улан-Удэ, МСК+5).

| Когда | Что происходит |
|---|---|
| Мгновенно (вебхук 1Denta) | Создание, перенос, отмена и удаление визитов, изменения пациентов и справочников попадают в DentaFlow сразу |
| Каждый час | Страховочная синхронизация с 1Denta (справочники, пациенты, записи) |
| Каждые 15 минут | Напоминания пациентам в ботах о визитах через 24 часа |
| Каждые 5 минут | Проверка необработанных заявок: новая заявка без реакции более 15 минут → уведомление «необработанная заявка» |
| 00:05 | Невыполненные автозадачи прошлых дней уходят в «Архив» |
| 02:30 | Полная ночная синхронизация: справочники, пациенты, расписание, звонки, маркетинг |
| 03:00 (08:00 Улан-Удэ) | Задачи «Подтвердить визит: {пациент} — {услуга} — завтра {время}» по всем записям **на завтра** — весь рабочий день, чтобы обзвонить пациентов |
| 03:05 (08:05 Улан-Удэ) | Проверка вчерашних визитов в 1Denta: пациент пришёл, но нет проданных услуг/оплаты/комментария → задача «Внести записи о приёме в МИС — {пациент} — {услуга} ({время} вчера): указать проданные услуги» |
| 03:10 (08:10 Улан-Удэ) | Напоминания о днях рождения сотрудников и врачей (за 1 день) |
| Любой пропущенный звонок | Задача «Перезвонить» с высоким приоритетом (без дублей) |
| Оплаченный визит | Начисление бонусных баллов пациенту |

## История обновлений

### Сентябрь 2026
- **Расписание:** время визита задаётся интервалом **«с … по …»** (длительность считается автоматически) в «Новой записи» и в деталях записи; в сетке показываются врачи, работающие по графику в этот день, даже без записей (доступны и в фильтре).
- **Бонусная программа:** баллы за **видеоотзыв** (по умолчанию 2000; кнопка «Видеоотзыв» в карточке, отдельная строка в статистике и правилах бота); **реферальный код пригласившего** в форме нового пациента с автоначислением баллов; **оплата баллами** на визите (курс балла, лимит %, кнопка «Максимум»).

### Август 2026 (вторая половина)
- **Заявки с сайта (Тильда):** телефон из формы больше не теряется; заявка сохраняется даже при ошибке разбора.

## Что недоступно для роли «Администратор»

| Раздел / действие | Причина ограничения |
|---|---|
| Аналитика (`/analytics`) | Финансовые KPI и выручка |
| Отчёты (`/reports`) | Детализированные бизнес-отчёты |
| Настройки (`/settings`) | Конфигурация клиники, интеграции, мотивация, источники пациентов |
| ИИ обзвон (`/ai-calling`) | Доступен только Владельцу и Управляющему |
| Добавление / изменение / удаление сотрудников | Управление учётными записями — Владелец/Управляющий (просмотр раздела «Сотрудники» и график врачей администратору доступны) |
| Сохранение настроек бонусной программы | Владелец/Управляющий (просмотр, начисления, модерация отзывов — доступны) |
